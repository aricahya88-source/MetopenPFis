# PATCH METOPEN PFIS v2.0.0 — Supabase

Patch ini ditujukan untuk repository METOPEN PFIS yang sama dengan file sumber yang diberikan.

## Cara paling aman

Gunakan ZIP project lengkap v2.0.0 sebagai pengganti repository lama.

## Jika memakai patch

1. Backup repository lama.
2. Timpa file/folder dengan isi patch.
3. Hapus file yang tercantum pada `DELETE_THESE_FILES.txt`.
4. Ikuti `MIGRASI_V2_SUPABASE.md` dan `PETUNJUK_PEMASANGAN.md`.

Apps Script v1 dipindahkan ke `apps-script-legacy/`. Runtime v2 hanya memakai `apps-script/` upload-only.
